Paste your GitHub access token once. It stays only in this browser on this device. Nobody else can publish without it.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new (signed in as a050121).
  2. Name: card shop editor. Expiration: the longest offered.
  3. Repository access: Only select repositories → a050121/card-shop.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else alone.
  5. Click Generate token, copy it, paste it above.

Changes are saved on this device until you press Publish. After publishing, the shop updates in about 1–2 minutes (sometimes up to 10).
